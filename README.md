# QR-Based Smart Restaurant Table Reservation System

## Overview

A Java Swing and MySQL-based restaurant reservation system that allows users to register, log in, book tables, prevent double bookings, order food, generate bills, and create QR codes for reservation verification.

## Technologies Used

* Java Swing
* JDBC
* MySQL
* ZXing QR Library

## Features

* User Registration
* User Login
* Table Booking
* Double Booking Prevention
* View Bookings
* Food Ordering
* Bill Generation
* QR Code Generation
